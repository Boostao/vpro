Attachment to the Agreement with BooSTAO for Biogeoclimatic Ecosystem
Classification integrated data and classification management system.

# THE SERVICES

1.  The Contractor shall provide the following Services:

The contractor will Build an integrated data and classification
management system for managing Biogeoclimatic Ecosystem Classification
data and information using R, R-shiny, PostgreSQL, and other open-source
tools for both a cloud and local machine environment. The contractor
will deliver clearly documented functions and scripts and working
products for the tasks outlined below.

1)  BEC DATA MANAGEMENT SCRIPTS

    a)  Build translation and syncing of VPro plot data and library code
        databases to cloud-based postgres database and equivalent
        open-source databases for local machine applications

        i)  Functions to allow controlled merging and information
            syncing of local and cloud-based datasets with change
            tracking.

        ii) Build functions to allow use of data stored in local compact
            RDS data tables instead of database form.

    b)  Build a map-based R-shiny tool for public access to BECMaster
        plot data and user download in multiple data formats

    c)  Tools to test data compliance with mandatory code standards.

2)  VPRO 2.0 SCRIPTS

    a)  Replace all functionality of Vpro64 in R based scripts for web
        and local machine applications

        i)  On-line and local data entry forms structured for FS882 and
            FS1333 field forms and two-page view as outlined in Vpro
            linked to code standards library.

        ii) Apply site unit table to limit data records viewed or
            reported

    b)  Tools to create and attribute site unit tables from multiple
        field characteristics

        i)  Write temporary classification between SU table and plot
            data

        ii) Filter records based on user defined profile of species and
            environment

    c)  Collapsable tree view of site unit - plots in site unit table

    d)  Create and store common data functions in BEC_R

    e)  Forms and function to combine species codes file for optional
        reporting

    f)  Hierarchy table

    g)  BECdb management (unit naming)

3)  BEC UNIT REPORTING SCRIPTS

    a)  Generate vegetation, environment and combination plot tables in
        Excle (with organization options from VPro)

        i)  Build excel add-in for highlighting and formatting exported
            tables for review

    b)  Generate working tables of unit summaries for author
        review/editing in Excel

        i)  Vegetation, Environment, and Combination summary tables
            (with Vpro organizational options)

        ii) Relative and Actual Edatopic grid outputs showing count of
            SMR and SNR in grid form

        iii) Download climr data for plots and summary with variables on
             in range of province

    c)  Generate publication ready graphics for classification units

        i)  Formatted Vegetation summary table (individual units or
            multiple units)

        ii) Formatted Environment summary table (SNR, SMR, Slope grade,
            Slope position, Parent material, Soil texture, Soil particle
            size, Coarse fragment content, Soil class, humus form, humus
            depth, important site features

        iii) Map of unit plot locations by base-map and/or colour-themed
             BGC range map

        iv) Box plots/histograms of unit site characters.

        v)  Aspect ordinal rose diagram

        vi) Hierarchy graphic

    d)  Build functions to generate unit summary report in html and PDF
        form from plot data and generated graphical elements

4)  BECWEB SCRIPTS

    a)  Build Quarto scripted BECWeb 2.0 website to house functions and
        include information currently available from BECWeb.

5)  BEC CLASSIFICATION ANALYSIS

    a)  Create analysis functions in BEC_R package from existing
        proto-scripts

    b)  Integrate analysis routines in Vpro placement to run analyses
        and return classification results to SU and Hierarchy Tables

6)  The ministry will provide working plot datasets, code libraries,
    VPRO program, other existing code products, and cloud-server
    architecture for hosting the project.

    1.  Outcomes:

        (a) Through the delivery of the Services the Province wishes to
            realize the following outcomes and, without limiting the
            obligation of the Contractor to comply with other provisions
            of this Part, the Contractor must use commercially
            reasonable efforts to achieve them:

- Replace the data management, classification and reporting functions
  currently delivered by programmed ACCESS database VPro with R and
  other open source tools with functionality both for centralized
  cloud-based system and for independent local machines.

- Integrate systems for managing provincial standards for species
  taxonomy, BEC codes, and accepted classification units with the BEC
  data management

- Build tools for public access to BECMaster plot data, classification
  products, and other BEC information.

- Build tools for generating formatted BEC site unit and BGC reports.

- Integrate data management system with BEC-R classification analysis
  package.

- Build tools for efficient off-line field collection of plot data from
  any device or from standard paper field forms

> The parties acknowledge that the Contractor does not warrant that
> these outcomes will be achieved
